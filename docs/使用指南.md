# 使用指南

[返回项目首页](../README.md) · [第一次评测](第一次评测.md)

## 安装与启动检查

先安装 Node.js 22.12+（包含 npm）和 uv，确认以下命令可用，再按 [README 快速开始](../README.md#快速开始) 在两个终端启动服务：

```sh
node --version
npm --version
uv --version
```

首次安装需要网络下载依赖；Python 3.12 由 uv 管理，无需另装 MySQL 或 PostgreSQL。后端迁移命令会创建 SQLite 数据库，两端启动终端都需保持运行。

启动成功后，访问 `http://127.0.0.1:5173/api/health` 应返回 `status: "ok"` 和 `database: "connected"`。首次打开聊天页没有模型和 Agent 是正常状态；先添加模型，再创建 Agent。通用助手案例需自行导入，不会自动预装。

| 遇到的问题 | 处理方式 |
| --- | --- |
| `uv`、`node` 或 `npm` 找不到 | 安装对应工具后重新打开终端，检查上面的版本命令 |
| 提示数据库表不存在 | 在 `backend/` 执行 `uv run alembic upgrade head`，再启动后端 |
| 8000 或 5173 端口被占用 | 先关闭此前启动的同一应用；前端代理固定连接本机 8000，勿只改后端端口 |
| 页面提示本地服务未就绪 | 确认后端终端仍在运行，检查健康接口，再点击重试连接 |
| 依赖下载失败 | 检查网络后重新执行 `uv sync --locked` 或 `npm ci`，保留锁文件 |

## 使用模型管理

打开 [模型管理](http://127.0.0.1:5173/models)，点击「添加模型」。填写服务商提供的模型标识、API Base URL 和 API Key。地址示例为 `https://api.openai.com/v1`；是否需要 `/v1` 以服务商说明为准，不要填写完整的 `/chat/completions` 地址。

上下文长度、最大输出长度按服务商说明填写，温度的建议值为 1。价格在“价格记录（选填）”中填写，支持币种与计价 Token 数；默认人民币 / 百万 Token。留空表示未知，填写 0 表示免费。保存后点击「测试连接」，会向该服务发送一条简短问候请求，最多请求 64 个输出 token，可能产生少量服务商费用。

本阶段使用 Chat Completions 的 `max_tokens` 与 `temperature` 参数。部分模型只接受 `max_completion_tokens` 或不支持温度，暂不适用这套调用参数；可通过连接测试确认兼容性。参数说明参见 [OpenAI 官方接口文档](https://platform.openai.com/docs/api-reference/chat/create)。

第一个模型自动成为默认模型。删除默认模型时，有其他模型就必须先选择替代项；删除最后一个模型后回到空状态。编辑时 API Key 输入框为空，留空保留原密钥，填写新值后替换。

升级旧版本后，重新执行 `uv sync --locked` 和 `uv run alembic upgrade head`，并重启未开启 `--reload` 的后端服务。

## 数据与配置

应用数据默认保存在 `backend/data/mini-agent.db`，该目录不会进入版本控制。初始迁移记录项目名称，后续功能继续使用这个 SQLite 数据库。

模型密钥加密保存。首次保存模型时，在 `~/.config/mini-agent/keys/` 生成对应数据库的主密钥文件；文件名是数据库绝对路径的 SHA-256 前 24 位加 `.key`。请分别备份数据库和主密钥。主密钥丢失会导致已存密钥无法解密，界面会提示恢复原文件。迁移数据库位置时，需将原主密钥复制到新路径对应的文件名。不要把数据库或主密钥放入版本库，也不要在已有配置时删除或重新生成主密钥。

如需更换数据库位置，在启动和迁移命令所在的终端设置同一个环境变量：

```sh
export MINI_AGENT_DATABASE_PATH=/absolute/path/mini-agent.db
uv run alembic upgrade head
uv run uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

相对路径始终基于 `backend/`。`.env.example` 只作为配置参考；应用不自动加载 `.env`，使用上述环境变量即可。

| 模块 | 地址 |

| 聊天 | `/chat` |
| Agent 管理 | `/agents` |
| 模型管理 | `/models` |
| 添加模型 | `/models/new` |

| 工具详情 | `/tools/:id` |

| 运行记录 | `/runs` |
| Agent 评测 | `/evaluations` |

Vite 开发服务器与 `npm run preview` 均支持直接访问和刷新上述地址。构建结果在 `frontend/dist`；preview 仅用于本机预览。

正式部署时，由静态服务器托管 `dist`，配置同源 `/api/` 反向代理到本机后端，其余页面路径回退到 `index.html`。例如 Nginx 的两个 location：

```nginx
location /api/ {
    proxy_pass http://127.0.0.1:8000;
    proxy_buffering off;
    proxy_read_timeout 3600s;
}

location / {
    try_files $uri $uri/ /index.html;
}
```

站点 `root` 需指向构建后的 `frontend/dist`。不要把 API 的 404 回退到前端页面。

## 使用工具管理

打开 [工具管理](http://127.0.0.1:5173/tools) 查看当前时间、Shell、文件读写三项内置工具，切换开关会保存到 SQLite。点击「查看详情」查看参数、默认配置、限制与调用示例。内置工具不可删除或修改用途。时间工具默认启用，Shell 与文件读写默认停用，使用前需启用。

默认时区为 `Asia/Shanghai`，可通过 `MINI_AGENT_DEFAULT_TIMEZONE` 配置。调用时可传 `Asia/Shanghai`、`America/New_York`、`Etc/UTC` 等 IANA 时区；不传则采用默认值，`CST` 等歧义缩写会被拒绝。

文件与 Shell 共用独立授权目录，默认是项目根目录的 `tool-workspace/`，首次执行时创建。也可在启动前设置 `MINI_AGENT_TOOL_ROOT=/absolute/path/workspace`；相对路径以 `backend/` 为基准。目录不能包含本应用代码、数据库、模型密钥或系统目录。把需要处理的普通文件复制进来，勿放入敏感内容。文件参数始终填写相对路径，父目录需已存在；仅支持 UTF-8 文本，最大 1 MiB。

| 操作 | 行为 |
| --- | --- |
| `read` | 读取现有文件；不传 `content`，不存在时报错 |
| `create` | 创建新文件；已有同名文件时报错 |
| `write` | 用 `content` 完整替换现有文件；不存在时报错 |

Shell 第一版适用于当前 macOS 环境，依赖系统 `sandbox-exec`。支持 `uname`、`ls`、`find`、`grep`、`cat`、`mkdir`、`test` 等系统命令及本地已检查的 Shell 脚本。完整命令白名单见 `backend/app/services/tool_shell.py`。Python、Node、包管理器和任意可执行文件尚未开放；授权目录外的项目测试不能直接在此运行。沙箱禁止联网，不能下载依赖或直接执行远程脚本。该系统接口已被 Apple 标为弃用，因此其他平台或沙箱缺失时返回不可用，不会转为普通命令执行。[Apple 说明](https://developer.apple.com/forums/thread/661939)

Shell 默认超时 10 秒、最多 30 秒；标准输出与标准错误合计最多 64 KiB，达到上限时中止执行。单进程 CPU 最多 30 秒、单文件最多 1 MiB、文件描述符最多 64 个；按当前用户进程数额外预留 32 个进程作为硬上限。仅用于前台任务，不支持守护进程或作业控制；清理范围为本次初始进程组。执行失败或中止不会回滚已经完成的文件改动。

统一调用接口为 `POST /api/tools/{id}/execute`，工具 ID 为 `current_time`、`shell`、`file`，请求体形如：

```json
{"arguments":{"timezone":"Asia/Shanghai"}}
```

结果包含 `tool_id`、`success`、`code`、`message`、`data` 和 `duration_ms`。命令结果的 `data` 包含 `stdout`、`stderr`、`exit_code`、`truncated`；非零退出码、超时、路径越权、工具停用和参数错误都有独立代码。业务执行失败返回 HTTP 200 与 `success: false`；请求格式错误返回 HTTP 422。接口仅开放给本机页面，拒绝跨站及非 JSON 写请求。

当前详情页展示调用说明；Agent 在聊天中可调用已绑定且启用的工具，沿用相同校验与执行限制。


## 使用 Skills 管理

打开 [Skills 管理](http://127.0.0.1:5173/skills)，点击「导入 ZIP」。压缩包包含一个 Skill：`SKILL.md` 可以位于 ZIP 根目录，也可以放在唯一的一级目录中。其他参考文件应与它放在同一 Skill 目录内。导入后会保存到当前项目的 `workspace/skills/`，默认启用；同名 Skill 或已有目录会拒绝导入，不覆盖原文件。

也可以手动创建 `workspace/skills/meeting-notes/SKILL.md`，采用以下格式：

```markdown
---
name: 会议纪要
description: 将会议记录整理为结论与待办
---

# 处理步骤
1. 提取已确认的结论。
2. 按负责人整理待办，缺失信息标注为待确认。

# 输出要求
分别列出会议结论、待办事项与待确认问题。
```

文件使用 UTF-8 编码。名称、用途说明和详细指令均为必填；名称最多 100 字，用途说明最多 500 字。目录名支持字母、数字、中文、短横线与下划线，不能以下划线开头。手动修改后点击「刷新」，无需重启服务；格式无效或名称重复的目录会显示原因，暂不提供给 Agent。

编辑页支持长篇 Markdown 指令。保存会更新原目录下的 `SKILL.md`，保留其他文件和额外 YAML 元数据。若文件已被外部修改，页面会提示冲突并保留未保存的输入；可先复制修改，再重新加载文件。

停用只改变本机 SQLite 中的状态，文件继续保留，刷新或重启后状态不变。删除需要在页面确认，随后删除整个 Skill 目录及全部附件。请按需备份 `workspace/skills/` 和数据库。Agent 运行时按需加载有效且启用的 Skill 正文；Skill 不执行代码，附件不会自动读取。

导入大小限制和格式要求也可在页面展开查看。接口包含列表、详情、刷新、导入、编辑、启停和删除；完整请求格式见 [本地接口文档](http://127.0.0.1:8000/docs#/skills)。

## 使用 MCP 管理

打开 [MCP 管理](http://127.0.0.1:5173/mcp)，点击「新增 Server」。按 Server 使用说明填写名称、启动命令、参数和可选环境变量。比如命令填 `node`，参数分别填 `/绝对路径/server.js` 和 `--stdio`；这些参数只是格式示例，实际值以所安装程序的说明为准。可执行文件必须已安装，参数按列表顺序原样传入，带空格的路径不需再加引号；相对路径以项目根目录为基准。

新建后默认停用。点击「测试连接」会真实启动本机程序、完成 MCP 初始化并发现工具，不调用工具。测试成功后可展开查看工具名称、用途、参数类型、必填项和完整 JSON Schema；没有工具时会明确提示。测试不会改变启用状态。启用并绑定到 Agent 后，聊天运行会发现并调用其可用工具。

环境变量值加密保存，编辑页面仅显示掩码。默认保留已有值，点击「替换值」可输入新值；移除变量行后保存会删除对应变量。修改命令、参数或环境变量后需重新测试；列表会保留最近成功发现的工具，并明确提示当前配置尚未重新验证。删除 Server 需确认，只删除配置与记录，不卸载本机程序。数据库与其独立主密钥需分别备份。

当前支持 stdio 初始化流程的协议版本为 `2024-11-05`、`2025-03-26`、`2025-06-18` 和 `2025-11-25`；不支持远程 HTTP、OAuth 或账号授权。连接过程参考 [MCP 初始化与关闭规范](https://modelcontextprotocol.io/specification/2025-11-25/basic/lifecycle)。本机 Server 按当前用户权限运行，请使用可信程序；测试会清理启动的进程组，不支持自行脱离进程组的后台服务。

配置接口和测试接口可在 [本地 MCP API 文档](http://127.0.0.1:8000/docs#/mcp) 查看。


## 使用 Agent 管理

打开 [Agent 管理](http://127.0.0.1:5173/agents)，点击「新建 Agent」。填写名称、说明和系统提示词，选择模型，并按任务需要勾选工具、Skills 和 MCP Server。新建时预选当前默认模型；没有模型时，页面提供添加入口。最大执行轮数默认 10，支持 1–100 的正整数；达到限制会停止本次运行并保留未完成正文。

系统提示词首次保存为 v1；之后仅在内容变化时新增版本，改名、切换模型或调整能力绑定不会增加版本号。编辑页显示当前版本与提示词，不提供历史版本比较或恢复。

只有启用的能力可以新增绑定。原绑定的能力后来被停用，编辑页会标记「已停用，不可用」，可以保留后保存其他修改，也可手动取消选择。列表中的数量包含停用绑定。手动修改 Skill 文件导致内容失效或缺失时，原绑定仍保留并显示不可用。

第一个 Agent 自动成为默认项；有多个 Agent 时，可在列表切换默认项。删除默认 Agent 需要先选择替代项，切换和删除一起完成。删除最后一个 Agent 后回到空状态。

模型、Skill 或 MCP Server 被 Agent 引用时，删除会被阻止，并显示相关 Agent 名称。先编辑这些 Agent 更换模型或移除绑定，或者删除 Agent，再删除资源。停用能力不会解除引用保护。Agent 配置、绑定、默认状态和提示词版本保存在 SQLite，刷新或重启后保留。

配置接口可在 [本地 Agent API 文档](http://127.0.0.1:8000/docs#/agents) 查看。


## 使用聊天

先添加模型并创建 Agent，再打开 [聊天](http://127.0.0.1:5173/chat)。点击「新建对话」会保存会话并预选默认 Agent；第一条消息保存后自动用消息开头命名。会话按最后消息时间排序，刷新或重新打开后可以继续。当前会话也记录在页面 URL 中。

Enter 发送，Shift + Enter 换行。发送后先保存用户消息，再流式显示回复；完成时显示「回复已保存」。「停止生成」、关闭页面或流式连接断开会取消当前运行；切换会话或离开聊天也会断开当前订阅。关闭或重启后端会中断生成，已有正文标记为未完成。

同一会话可以切换 Agent，新回答使用新的模型与系统提示词，并基于本会话有效历史构造上下文。旧回复保留原 Agent 名称。已删除 Agent 的会话仍可查看，继续发送前需选择可用 Agent。回答过程中可调用该 Agent 已绑定且启用的工具与 MCP 能力。模型先看到 Skill 目录，需要时通过 `load_skill` 加载完整指令，再继续处理任务。

失败或停止时保留用户消息和已有正文，未完成回答不会用于后续上下文。若提示回复保存失败，请复制保留正文。接近上下文容量时，启用自动压缩的 Agent 会尝试摘要较早对话；压缩无法满足容量时会提示缩短输入或新建会话。原始聊天记录保留；不同兼容模型的 tokenizer 不统一，本地容量检查采用保守估算。模型服务需支持流式 Chat Completions、`max_tokens` 与流式用量选项；使用工具时还需支持 `tools` / `tool_calls`。

会话右侧的「···」提供置顶、重命名和删除。删除需确认；正在生成时先停止再删除。侧栏历史对话按最近会话时间倒序，分为「今天 / 昨天 / 一周 / 更早」；点击标题可折叠整个历史或单独时间组，搜索只筛选列表，不影响当前草稿。

### 附件与回复操作

输入框左下角的 **+** 可以添加文件或查看 Agent 能力。文件显示为可移除的 Chip，点击发送才保存并调用模型。

支持 PNG、JPEG、WebP、静态 GIF、PDF、TXT、Markdown、CSV、JSON。单文件最多 **5 MiB**，每次最多 4 个、合计 10 MiB。文本须为 UTF-8，提取文本合计最多 100,000 字符。PDF 最多 50 页，仅提取文本；扫描件请转为图片。图片理解需所选模型支持视觉输入，暂不支持音频、视频和 Office 文件。

历史附件随会话保存在本机，删除会话会同时删除附件。回复支持 Markdown、代码高亮和代码复制。最后一次提问可以重新生成或重试：原回复保留，本地与 MCP 工具不会再次执行，后续对话使用最新完整回答。


### 将输出保存到本地文件夹

在空对话输入框下方的灰色上下文栏点击「选择本地文件夹」，直接使用 macOS 文件夹选择器选定一个目录。取消选择会保留原绑定；发送前可用文件夹旁的关闭图标取消绑定。每次对话只能绑定一个目录，发送第一条消息后固定；新建对话清空输入并重新选择目录。

选择范围为本地授权工作目录（默认项目根目录的 `tool-workspace/`），可在启动前通过 `MINI_AGENT_TOOL_ROOT` 指定其他独立工作目录。目录需已存在或由应用创建授权根目录，隐藏目录和符号链接不能绑定。

完整 Agent 回复会自动保存为 `reply-<消息标识>.md`，会话记录保存为 `conversation-<会话标识>.md`。再生成会保留旧回复的 MD；未完成回复只保留在会话记录中。Agent 已绑定且启用文件工具时，工具生成的文件也写入所选目录。单条回复 MD 最多 1 MiB；同步失败时，在上下文栏点击「重试同步」。删除应用中的对话不会删除文件夹里的副本。不选择文件夹时仅保存在应用中。

会话列表按最近消息时间倒序排列，按今天、昨天、一周和更早分组。将鼠标移到会话上，点击「···」可重命名、修改归属或删除；也可直接把会话拖到项目上。键盘聚焦会话后可访问相同操作。
