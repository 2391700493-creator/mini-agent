## 目录与代码入口

| 目录 | 内容 |
| --- | --- |
| `frontend/src/pages/`、`frontend/src/components/` | 路由页面与共享组件 |
| `frontend/src/router/`、`frontend/src/stores/`、`frontend/src/api/` | 导航、状态和 `/api` 请求 |
| `frontend/src/composables/`、`frontend/src/utils/` | 组合式函数与辅助函数 |
| `frontend/src/styles/` | 全局样式与设计 token |
| `frontend/src/assets/` | 前端资源及第三方资源许可 |
| `frontend/tests/` | Vitest 页面与交互测试 |
| `backend/app/api/`、`backend/app/schemas/` | FastAPI 接口与请求 / 响应结构 |
| `backend/app/services/` | Agent 执行、能力管理、聊天与评测逻辑 |
| `backend/app/models.py`、`backend/app/repositories/` | SQLAlchemy 模型与数据访问 |
| `backend/migrations/` | Alembic 迁移环境与版本链 |
| `backend/tests/` | pytest 测试，使用临时数据与模拟模型 |
| `examples/general-assistant/` | 助手提示词、Skill 源文件与导入配置说明 |
| `docs/archive/` | 历史审查、验收记录与基线截图 |

核心服务职责见 [架构说明](架构说明.md)。前端统一请求 `/api`，开发代理连接本机后端。

## 依赖与检查

前端使用 npm，后端使用 uv。保留并提交锁文件；Python 保持 `>=3.12,<3.13`，TypeScript 固定 `~5.9.3`，升级时与 `vue-tsc` 一起验证。

```sh
# frontend/
npm ci
npm run test
npm run build

# backend/
uv sync --locked
uv run pytest
uv run ruff check .
uv run ruff format --check .
```

按改动风险选择检查：文档只核查链接与内容；单一功能先运行相关测试。数据库、权限、文件系统、Runtime 或跨端变化需要针对性测试，影响较大时再运行两端全量检查。

数据模型改动须生成并审查 Alembic 迁移。使用临时数据库验证升级、回滚、再升级及 `uv run alembic check`；不要对正式数据库做验证性回滚。数据库测试已有隔离配置，手动执行迁移检查前也必须设置独立的 `MINI_AGENT_DATABASE_PATH`。

## 本机数据与发布范围

`backend/data/` 存正式数据库，`workspace/skills/` 存个人导入的 Skills，`tool-workspace/` 存授权工作文件，`.workbuddy/` 存本机辅助记录。这些目录已被 `.gitignore` 排除，保留在本机。`node_modules/`、`.venv/`、构建输出和缓存同样不进入版本库。

示例放在 `examples/`，与个人工作内容分开。主密钥位于项目外；具体数据路径、配置方式和备份说明见 [使用指南](使用指南.md#数据与配置)。公开前检查待提交文件及历史，确保没有数据库、凭据或个人文件。
