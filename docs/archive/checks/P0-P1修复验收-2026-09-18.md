# P0 / P1 修复验收

范围来自任务「审查产品 UI 与交互优化点」的第一批清单，共 1 项 P0、6 项 P1。仅修改前端。

| 优先级 | 内容 | 结果 |
| --- | --- | --- |
| P0 | 运行指标遮挡记录列表 | 指标、列表独立渲染；加载与失败期间不展示错误空状态 |
| P1 | 复核取消仍提交 | 改用原生 dialog，取消与 Esc 不请求接口；提交失败保留备注，关闭恢复焦点 |
| P1 | 数据集编辑状态混乱 | 查看、新建、编辑分开；编辑自动回填；明确新建入口 |
| P1 | 模型和 Agent 未保存保护 | 共用内存快照，拦截路由离开与刷新；保存成功更新快照；不写入浏览器存储 |
| P1 | 历史消息静默丢弃 | 改为角色与正文逐条编辑，保留多行正文；存在空消息时明确提示序号并阻止保存 |
| P1 | 评测重复提交 | 写操作增加请求锁和禁用状态；保存、启动、停止、重跑、复核提供进行中文案 |
| P1 | 输入边界不明显 | 灰卡内使用白色表单控件，补充边框、聚焦与错误状态 |

验证：`npm run test` 全部通过（13 个文件、109 项测试），`npm run build` 通过（包含 TypeScript 检查）。新增 8 项回归测试覆盖上述主要故障及失败恢复。

浏览器检查 1440、899、390px：八个模块切换成功、路由焦点正确、无整页横向溢出。另检查评测页刷新、运行页离线提示和重新加载，以及数据集编辑回填与保存。浏览器写操作使用 /tmp 下独立 SQLite 数据库、密钥及工作目录，未修改正式数据。

原生离开确认框触发后，浏览器控制工具超时，未完成该确认框的浏览器交互验收；取消离开、刷新拦截与还原字段后的放行已通过自动化测试。复核的取消、Esc、失败保留备注与成功关闭也已通过自动化测试。
