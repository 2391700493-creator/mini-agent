# Mini-Agent 设计规范

本规范根据用户提供的 Apple DESIGN 与 tokens 整理，适用于所有已实现的页面。操作色统一为近黑色，使用现有功能与真实数据。

## Design Context

### 用户与任务

面向学习和开发 Agent 的本地单用户。主要任务是连接模型、组合 Agent 的指令与能力、开始对话、回看历史、安排重复任务和检查执行结果。

### 语气与视觉

简洁、平静、清楚。使用中文短句。白色画布、浅灰表面、SF 字体与黑色操作。减少装饰，让任务内容和当前状态容易识别。

### 原则

1. 首屏只显示当前任务需要的内容。高级参数、技术配置和执行过程按需展开。
2. 页面之间复用相同导航、标题、控件、焦点和反馈样式。
3. 黑色用于主要操作和正文，灰色用于表面、选中状态和辅助文字。
4. 保留真实状态、数据来源与操作边界；不添加虚构成绩、账号或模块。
5. 桌面优先。窄桌面可以折叠主栏，重要功能始终可访问。

## 颜色与表面

| 角色 | 值 | CSS token |
| --- | --- | --- |
| 白色画布、菜单和输入控件 | #ffffff | --surface-canvas |
| 浅灰内容区和卡片 | #f5f5f7 | --surface-card |
| 导航背景 | #fafafc | --surface-hover |
| 选中项、停用控件 | #e6e6e8 | --surface-selected |
| 正文、主操作、链接、焦点 | #1d1d1f | --color-ink |
| 辅助文字 | #707070 | --color-text-secondary |
| 控件轮廓 | #d6d6d6 | --color-outline |
| 分隔线 | #e6e6e8 | --color-border |
| 边缘与非活动标记 | #86868b | --color-steel |
| 运行上限、部分完成等状态 | #b64400 | --color-launch-orange |
| 错误与危险操作反馈 | #a32d28 | --color-error |

原参考的两种蓝色均映射为 #1d1d1f。状态不能只靠颜色表达，必须配文字。输入区无投影。内容卡片使用透明细轮廓、贴近表面的接触阴影和低透明度环境阴影；悬停只轻微增强阴影，引导卡可上浮 3px。已启用能力卡使用浅灰底和轻微内阴影表达按下感。菜单和弹窗使用更高一层的柔和投影。禁止渐变、彩色选中底和重阴影。分隔线保留真实边框，高清屏使用 0.5px。

## 字体与排版

优先使用本机 SF Pro Display / SF Pro Text，回退到系统字体和苹方、微软雅黑。字体文件不随应用分发。

| 用途 | 大小 / 字重 | 行高 |
| --- | --- | --- |
| 页面标题 | 40px / 600；窄桌面 28px | 1.2 |
| 卡片名称、内容标题 | 24px / 600 | 1.33 |
| 分组标题 | 19px / 600 | 1.4 |
| 主说明、聊天正文 | 17px / 400 | 1.47 |
| 标签、按钮、用途说明 | 14px / 400–500 | 1.43–1.6 |
| 能力卡描述 | 13px / 400 | 1.6 |
| 时间、辅助说明、状态 | 12px / 400 | 1.33–1.6 |

页标题与卡片名称用 Display，正文与控件用 Text。代码、JSON 和参数示例才使用等宽字体。长名称可换行，单行历史标题截断时保留完整提示。

## 尺寸与布局

以 4px 为间距单位。常用间距为 8、12、16、20、24、28、32、40、48、64px。

- 管理页面内容最大宽度 1040px，聊天输入区最大宽度 800px，AI 回复最大宽度 960px，模型配置表单最大宽度 760px；正常桌面页面边距 64px，窄桌面 32px。共享容器沿用现有桌面断点，不针对单个截图尺寸设置规则。
- 主侧栏展开宽度 280px，可独立折叠；顶部操作与底部工作空间入口固定，历史列表独立滚动。
- 内容卡片和弹窗圆角 28px，能力卡内边距 22px，引导卡与 Agent 卡 24px；窄桌面能力卡内边距 20px。
- 小内容面板与长文本输入圆角 20px；列表项圆角 10px。
- 按钮与紧凑选择器为胶囊形。配置表单输入使用 12px 圆角、48px 最小高度；主按钮高度 40px，其他输入控件通常 44px。
- 卡片网格使用流式列宽，不将大量内容挤入固定小格。

## 共享组件

### 主导航与历史对话

Agent 管理直接作为一级导航，能力工坊与观察评测按组展开；定时任务保留单独入口。所有路由使用同一品牌标记、图标、文字尺寸和展开宽度。

历史对话保留搜索与时间分组。每条记录按标题、更新时间、置顶或生成状态阅读。当前聊天使用灰底黑字；其他页面不误标记当前对话。更多操作在选中、悬停、键盘聚焦时显示，位置固定。搜索和分区展开不丢失聊天草稿。项目条目使用 10px 圆角的紧凑行，左侧展开箭头、文件夹图标和名称，右侧保留新建对话与更多操作；悬停、展开和键盘聚焦使用同一灰底。

### 页面标题与操作

左侧显示标题和一句说明，右侧放主要操作。新增操作统一使用加号图标。页面主要按钮使用黑底白字；刷新、编辑与取消使用次级或文字操作。操作按钮可以换行，不能挤压标题。

### 能力卡片

模型、工具、Skills、MCP 复用接近白色的表面、透明轮廓与叠层轻阴影和底部操作区。卡片主体链接到详情，启停、测试和删除独立可操作。已启用卡片加深灰底并使用轻微内阴影，状态仍有文字和开关。完全空时只显示一张引导卡。

名称粗黑，用途说明使用较深灰色的 13px 正文，最多两行；系统来源与更新时间低强调。完整描述、参数、工具定义和连接配置放入详情。

所有管理卡片的名称与操作悬停不加下划线。引导卡整个区域可点击。默认最小高度 240px；悬停上浮 3px 并显示柔和投影，180ms 平滑过渡。减少动效时取消位移与过渡。

### 聊天输入与回复操作

输入区是单层白色容器，细灰边界、24px 圆角；文本区默认 44px 高，透明背景、无圆角、无描边和阴影；加号为浅灰圆按钮。发送或停止按钮固定在右下角，圆形清空按钮紧邻其左侧。工作目录入口放入加号菜单，通过弹窗选择已授权目录。

完成回复不显示“回复已保存”等常驻提示；生成状态、错误与保存失败仍需明确。AI 回复底部显示复制、分享、反馈、重新生成四个图标，悬停或键盘聚焦显示黑色提示。分享仅复制内容；反馈入口用点赞与点踩组合图标，仅提供有帮助／没帮助，存入本机 SQLite。重新生成沿用最新回复限制。Agent 菜单宽度最多 360px，每项使用头像、名称、两行用途说明及选中勾；用途说明允许换行，完整内容保留文字提示。

### 配置表单

字段标签常驻，说明紧随字段。错误标记对应字段并保留输入。已有配置的保存语义、密钥处理与默认选项保持明确。

模型连接首屏包含地址、模型名称和 API Key。配置区使用白色画布，字段组不再叠加灰色底板；标签、浅灰输入控件和较轻说明逐层排列，字段间留 28px。测试连接是主要操作，单独保存为次级操作；高级参数与价格记录默认折叠。

Agent 首屏包含身份与模型、完整任务要求两个区域；能力、运行上限、压缩设置和跨会话记忆按需展开。基础信息与任务要求使用白色面板；能力选项使用 #f2f2f2 灰底、16px 圆角、原生勾选框和独立详情入口，选中后加深灰底及外边界。能力名称为 14px 半粗体，用途为 12px 正文、最多两行。焦点只在整块选项外轮廓显示。

技能编辑把名称与用途说明直接排列在画布上，详细指令独立编辑；长文本使用等宽字体，保存操作随页面滚动保持可见。

### 定时任务、运行记录与评测

沿用相同卡片、输入与弹窗。定时任务显示真实计划与执行状态。运行记录保持表格与时间线，筛选和状态标记引用共享 token。评测保留数据集与任务结构，标签页使用黑白胶囊控件，结果详情渐进展开。

### 反馈、菜单与弹窗

普通提示为浅灰、错误同时显示文字。模型、Agent、Skill、MCP、会话、项目、定时任务、评测、运行记录与跨会话记忆的删除都采用居中原生弹窗，初始聚焦取消，取消后返回触发按钮；删除失败保留弹窗并在其中提示。菜单用透明轮廓与柔和悬浮阴影区分层次，并保留键盘操作；弹窗采用白底、28px 圆角、更高一层的投影、清晰标题及分级按钮。嵌套圆角按外圆角减去间距计算；间距超过 24px 的独立表面各自取值。

关键动效沿用原生 CSS：聊天等待用低幅度呼吸圆点，复制反馈图标切换为 120ms；聊天菜单从触发侧淡入，进入 180ms、退出 120ms；原生弹窗与遮罩同步进入 220ms、退出 160ms。离场菜单立即退出操作范围，焦点即时恢复。只过渡透明度和变换，不动画化首屏、消息正文、导航或列表；键盘触发与减少动态效果设置均使用即时切换。

输入控件只显示一根外轮廓。聚焦时在原边界位置加深描边，不额外绘制分离的外圈。搜索、聊天和日期范围等组合输入由外容器承载焦点，内部输入不再画边框、轮廓或阴影。

## 可访问性与验收

所有交互保留可见黑色焦点、无障碍名称与禁用状态。支持减少动效。不会因主题修改扩大工具权限、改变数据持久化或自动执行测试请求。

验收按改动风险决定。样式以构建和关键页面检查为主，验证正常桌面 1440px；涉及侧栏再检查 899px。关键表单和菜单复用已有交互测试。

## 实现文件

- docs/design-tokens.json：用户提供 token 的本地版本，蓝色操作色已改为 Ink。
- frontend/src/styles/tokens.css：全产品语义 token 与兼容别名。
- frontend/src/styles/workspace.css：主侧栏、历史记录、聊天工作空间。
- frontend/src/styles/product.css：共享标题、按钮、资源卡片、表单、弹窗、运行与评测。
- frontend/src/styles/agents.css：Agent 管理组件的具体布局。

旧版首页试用规范不再作为实现依据。
