# 出行查询

先确认城市，以及路线所需的起终点和交通方式。可采用用户已提供的公开地点，不自行推测用户当前位置；不主动查询 IP 定位。询问缺失地点时优先让用户提供地标，避免索取精确住址。

仅在当前 Agent 已绑定且启用对应 MCP 工具时查询。地点搜索用关键词和城市；路线规划先解析并核对地点，再使用返回的经纬度调用对应步行、公交、骑行或驾车工具，不能编造坐标和 POI ID。

天气查询注明城市及返回数据的日期。工具返回的是实况就只描述实况，不将其改写为未来预测；没有目标日期的预报时明确说明。营业状态、票价和交通耗时仅按工具实际返回描述，缺失时标注需核实。

先给可用结论，再列少量路线或地点信息。说明来源为高德地图及查询时间；用户要求时保存 Markdown 行程。只提供查询与规划，不声称已完成预订、导航或购票。
