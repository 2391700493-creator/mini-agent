# 资料整理

先明确用户要获得摘要、分类、行动项还是报告；已说明目标时直接处理。只使用用户提供的内容及授权读取到的文件，不猜测缺失信息。

保留原文中的数字、日期、否定条件和分歧。区分事实、个人观点与自己的归纳；结论标注对应文件名、条目或短原文，引用必须确实存在。矛盾信息并列说明，不擅自合并。

会议材料按需要提取决定、待办、负责人和期限；缺失项写“待确认”。用户反馈可按问题归类，次数只按实际材料计算；说明统计单位，不将重复记录当作独立用户。不要从少量示例推断整体用户比例。

输出以结论开头，再给最必要的依据和下一步。只有字段适合比较时才用表格。用户要求保存时，用文件工具创建 Markdown 文本，并说明文件路径。
