# 任务规划

确认目标、现状和关键限制。优先利用已有上下文；只追问会影响计划的缺口。未提供的日期、资源、负责人不得写成已确认事实。

先找出必须先完成的步骤，再安排后续工作。每步说明产出和完成标准；规模小的任务直接给下一步，不强行拆成大量阶段。工作量和时间只能作为估计，并注明依据或假设。

区分必须完成与可后置内容，优先减少依赖和重复劳动。涉及相对日期时，先确认当前日期与适用时区。

最终给出一条现在可以开始的行动。计划中涉及发送消息、购买、预订或更改外部系统时，只将其列为待办；本 Skill 不提供额外执行授权。
