# 通用助手

基于 Mini Agent 配置的通用助手：日常问答、资料整理、任务规划、本地文本处理，以及通过高德 MCP 查询地点、天气和路线。

## 配置

先配置并测试一个支持工具调用的 Chat Completions 模型。新建 Agent，名称填“通用助手”，将 [system-prompt.md](system-prompt.md) 原样填入系统提示词。

将 skills 下的三个目录分别压缩为 ZIP，通过 Skills 页面逐个导入，再绑定到 Agent。每个 ZIP 只包含一个 Skill，且保留对应目录名称：organize-notes、plan-tasks、plan-outings。

绑定当前时间、文件读写和受限 Shell。Shell 用于授权目录内的列表与搜索，依赖 macOS 沙箱；其他平台可取消 Shell 绑定，直接提供已知文件路径。

MCP 使用 `@amap/amap-maps-mcp-server` 的本机 stdio 服务：命令 `npx`，参数分别为 `-y` 与 `@amap/amap-maps-mcp-server`；环境变量 `AMAP_MAPS_API_KEY` 使用你自己的高德 Key。先测试连接，再启用并绑定。没有高德 Key 时可先不绑定 MCP，也不绑定 plan-outings，问答、资料与计划功能仍可使用。服务配置沿用当前本地实例；复现时应根据实际安装版本核对供应商说明。

推荐运行限制：最多 10 轮、300 秒、30 次工具调用；开启自动压缩，保留最近 4 轮。模型、密钥与机器路径由使用者自行配置，本目录不包含本地数据库或凭据。

## 可以直接尝试

**资料整理**：整理这段会议记录，提取决定与待办，不补充缺失信息：“小王周五前整理用户反馈；小李负责界面方案，时间未定；上线日期待确认。”

**任务规划**：我想在两周内发布一个本地 Agent 项目，每天约两小时。先给我最小发布范围和今天的第一步。

**地图查询**：查询杭州市当前天气，注明数据日期和来源；如果没有未来预报，不推测明天天气。

**本地文件**：将上面的计划保存为授权工作目录下的 `my-plan.md`，已有同名文件时不要覆盖。

运行记录可以观察 Skill 加载、模型请求与工具调用。以上是使用示例，不是性能基准；通用助手不具备任意网页搜索、浏览器控制或办公二进制文档解析能力。
