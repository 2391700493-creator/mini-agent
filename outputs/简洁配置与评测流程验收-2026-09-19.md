# 简洁配置与评测流程验收

本轮集中在首次配置、试用、评测和仓库说明。沿用现有 Vue、FastAPI、SQLite 和 Runtime，不迁移第三方框架。

## 已完成

模型价格配置按需展开；连接测试成功后可以直接创建使用该模型的 Agent。Agent 创建先展示任务、模型与提示词，工具与技能、运行参数及记忆折叠展示；校验错误会展开对应区域。Agent 列表新增“开始对话”和带入目标 Agent 的评测入口。

评测首次进入时解释数据集的用途，并提供示例入口。查看用例与编辑表单分开，从数据集可以直接开始评测；历史消息与过程规则按需展开。没有模型或 Agent 时只显示补齐配置的下一步，空数据集不能启动。启动时明确模型调用费用与工具副作用；查看结果时收起创建表单，提供调整 Agent 的入口。已经创建但启动失败的任务可以继续启动，避免重复创建。

README 从 231 行缩减到 77 行，保留定位、主流程、启动与核心实现；新增架构说明、第一次评测与完整使用指南。修正 README 和 AGENTS 中关于运行记录与评测尚未实现的过期说明。本轮参考开源项目的流程与信息组织，没有移植第三方代码。
