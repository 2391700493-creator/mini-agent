# 安装流程验收

## 结论

当前源码在 macOS 26.5.1 / Apple Silicon 上，按 README 可以完成依赖安装、数据库初始化和前后端启动，未发现阻塞安装的问题。

## 环境与隔离

Node.js 24.19.0、npm 12.0.2、uv 0.12.5、Python 3.12.14。复制源码到独立临时目录，排除 node_modules、.venv、数据库、环境文件和个人工作目录；npm 与 uv 使用新的下载缓存。Python 解释器沿用机器上已由 uv 管理的版本，所以这不是全新操作系统验证。

项目当前未初始化 Git 仓库，本次验证的是源码副本，不是从 GitHub clone 的版本。
